This repository contains the projects completed during my internship at **Oasis Infobyte**. The tasks cover the end-to-end data lifecycle, including Exploratory Data Analysis (EDA), Data Cleaning, Visualization, and Machine Learning.

---

## 📁 Project Overview

### 1. Retail Sales EDA 🛍️
**Goal:** Uncover consumer behavior and seasonal trends from 1,000 retail transactions.
* **Key Findings:** Identified a revenue peak in May ($53,150) and determined Electronics as the top-performing category.
* **Tech Stack:** Python, Pandas, Seaborn, Matplotlib.
* **Highlights:** Time-series analysis and demographic segmentation.

### 2. Data Cleaning Mastery (Airbnb NYC) 🏠
**Goal:** Transform "messy" real-world data into a structured, analysis-ready format.
* **Challenges:** Handled 10,000+ missing values in review data and removed 48,000+ null entries in ghost columns.
* **Key Steps:** Implemented IQR-based outlier detection for prices and standardized categorical features.
* **Outcome:** Created a high-integrity dataset for reliable property market analysis.

### 3. Interactive Tableau Dashboard 📈
**Goal:** Build a visual narrative for business stakeholders using the cleaned Marketing/Retail data.
* **Features:** Dynamic filters, KPI cards for Total Revenue, and Category performance breakdown.
* **Design:** Focused on UI/UX by implementing custom layouts and clear visual hierarchies to drive data-driven decisions.

### 4. Twitter Sentiment Analysis (NLP) 🐦
**Goal:** Develop a Machine Learning model to classify public opinion into Positive, Neutral, or Negative sentiments.
* **Dataset:** 160,000+ Tweets.
* **NLP Techniques:** TF-IDF Vectorization and stop-word removal.
* **Model:** Multinomial Naive Bayes, achieving **70% Accuracy**.
* **Visuals:** Confusion Matrix and Sentiment Distribution bar charts.
